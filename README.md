## 🖥 System Monitor Tool (C++)

The System Monitor Tool is a C++ application designed to display real-time system information such as running processes, CPU usage, and memory utilization — similar to the Linux top command.

This project demonstrates how system-level data can be gathered and visualized using system calls, process management, and real-time data refreshing in C++. It provides an interactive interface where users can monitor system performance and manage processes effectively.


---

## ✨ Key Features

📊 Display list of active system processes.

💾 Show CPU and memory usage for each process.

🔁 Real-time updates (auto-refresh every few seconds).

⚙ Sort processes by CPU or memory usage.

❌ Ability to terminate (kill) unwanted processes.


---

## The project was developed in stages over five days:

Day 1: Designed the user interface and accessed system data using system calls.

Day 2: Displayed process list with CPU and memory usage.

Day 3: Added sorting features by CPU and memory usage.

Day 4: Implemented process termination (kill) functionality.

Day 5: Added real-time auto-refresh to update system stats periodically.


---

## 🧠 Concepts Used

- System calls for process and resource monitoring.

- File handling and parsing system information.

- Process management using C++.

- Real-time data refresh using loops and sleep functions.

- Modular program design for clarity and scalability.
